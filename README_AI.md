# 给安装助手的说明

本文件负责将本仓库的技能交付到用户指定环境。编码和审查时的规则入口是 [skills/secure-coding/SKILL.md](skills/secure-coding/SKILL.md)，不要将本文件当作运行时指令重复加载。

## 1. 确认任务与位置

- 只有用户请求安装、更新或移除时才执行相应写入。仅阅读、评估或审查本仓库时保持只读。
- 根据当前会话确定本仓库的绝对路径，以及目标业务项目。两者可能是不同目录；不要把分发仓库误当作安装目标。
- 默认项目级目标为 `<目标项目>/.agents/skills/secure-coding/`。项目已明确时直接继续；无法确定目标时，只询问缺失的位置。
- 只有用户要求个人全局安装时，才使用 `~/.agents/skills/secure-coding/`（Windows 为 `%USERPROFILE%\.agents\skills\secure-coding\`）。其他客户端先核实其发现路径，不假定兼容。
- 遵守用户已授权范围和目标项目指令。不要仅为安装此技能更改全局配置、安装依赖、创建远程仓库或发布内容。

以下步骤中的源始终是**本文件所在仓库**的 `skills/secure-coding/`，不受执行命令时的工作目录影响。

## 2. 检查并复制完整包

先检查源目录内有 `SKILL.md`、`LICENSE`、`NOTICE.md`、`references/`、`sources/`、`scripts/`、`tests/`。保留整个目录及其相对结构；不能只复制 `SKILL.md`，也不能删除暂时不用的语言。

确认源与目标的实际绝对路径。若两者相同，无需复制；若路径重叠、现有目标是链接或实际指向项目外，先核实它是否符合用户预期，再进行写入。

如果目标已存在，先比较文件和本地修改：完全相同则跳过复制；有差异则展示差异与更新范围，沿用已有更新授权，不覆盖未经授权的本地定制。不要用删除目录再复制的方式处理冲突。

新安装时，将完整源目录复制到目标。复制后对照源目录逐文件检查完整性，保留许可证、署名和原文。所有工具命令使用目标技能的实际绝对路径并正确引用含空格的路径。

如用户希望在项目中明确启用此规则入口，可将 [examples/AGENTS.md](examples/AGENTS.md) 的段落合并到目标项目已有 `AGENTS.md`，保留其他内容并避免重复。该模板按项目级 `.agents/skills/secure-coding/` 安装编写；个人安装时应使用真实技能路径，不照搬相对链接。

## 3. 验证安装

有 Python 3.10+ 时执行以下只读命令，将占位符替换为目标技能的绝对路径：

```sh
python "<已安装技能绝对路径>/scripts/guide.py" check
python "<已安装技能绝对路径>/scripts/guide.py" show PY-BACKEND-1.2.1
python "<已安装技能绝对路径>/scripts/guide.py" list --language go
```

检查实际退出状态及输出：

- `check` 应通过 225 条规则、6 份来源、10 项适用性解释及相关生成内容/引用校验。
- `show` 应返回规则正文、原文位置和来源哈希；相关规则有适用性解释时一并返回。
- Go 列表应包含 37 条规则。

不要为安装运行 `build`；它用于维护生成文件，会写入内容。以上命令不联网，也不执行原指南中的代码示例。

如果找不到 Python 或版本不足，核对文件完整性并说明：**Markdown 规则可读，脚本校验未执行**。不自动安装 Python，不把降级使用报告成完整验证通过。

最后检查客户端是否列出 `secure-coding`，并在支持时显式调用它读取一项规则。若当前环境无法观察客户端发现或运行行为，报告“文件安装完成，客户端发现/调用待验证”，不要推断自动触发成功。必要时提示用户重新打开项目或重启客户端。

## 4. 交付、更新与移除

安装报告保持简短，列出实际源/目标路径、复制或合并的文件、执行的命令及结果、未验证事项，并给出第一次使用的请求：

> 请使用 secure-coding 技能完成本次改动，说明适用规则 ID、对应代码位置、实际检查结果及未验证事项。

更新时重新比较完整包，保留本地修改与许可证，再执行同样的校验。安装失败时先指出具体缺失文件或命令错误；修复后复验受影响步骤，不反复覆盖整个目录。

用户要求移除时，先确认目标路径确实是该技能的安装目录，并核对其中的本地修改。只移除已授权的技能内容和此前新增的入口段落，保留其他技能、项目指令和配置。
