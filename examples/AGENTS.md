# 安全编码指南

新增、修改或审查 C/C++、Go、Java、JavaScript/TypeScript、Python 代码及相关运行配置时，先读取 [secure-coding 技能](.agents/skills/secure-coding/SKILL.md)，按实际语言、运行环境和本次操作加载适用规则。TypeScript 复用其中 JavaScript 的运行时安全规则。

遵循适用的“必须”项及技能中有出处的解释；“建议／推荐”项按项目约束判断。交付前检查最终改动，运行项目已有的相关检查，并说明发现的问题与未验证项。范围扩大时补读相应规则。纯文档、翻译及不涉及代码行为的任务无需加载。

规则无法读取、与项目已批准政策冲突或适用条件不清时，指出具体缺口；不能把缺少依据表述为检查通过。此入口不授予额外安装依赖、部署、发送信息或修改外部系统的权限。
