# 共性检查入口

以下是供选择规则的共性摘要，不是对五份指南的替代，也不扩大原文级别。只检查本次实际涉及的行为，具体要求、示例和限制从语言索引读取。

| 改动触及 | 实现时关注 | 代表性原文规则 ID |
|---|---|---|
| 外部输入进入数据库/进程/模板 | 区分数据与命令；绑定参数、约束参数语义、按输出上下文处理 | PY-BACKEND-1.2.1、JS-NODE-1.2.1、JAVA-BACKEND-1.5.3 |
| 用户访问或修改对象 | 可信登录身份、功能权限、对象/租户归属；前端检查不能替代后端授权 | PY-BACKEND-1.8.1、PY-BACKEND-1.8.3、JAVA-BACKEND-1.9.3 |
| 文件或外部 URL | 约束目标范围及资源用量，检查规范化/重定向后的实际目标 | PY-BACKEND-1.4.3、GO-BACKEND-1.3.1、JS-NODE-1.3.2 |
| 凭证、密钥、个人数据、日志 | 避免硬编码和不必要暴露，按业务权限及最小化原则输出 | PY-COMMON-2.3.2、GO-COMMON-1.5.2、JAVA-BACKEND-1.9.1 |
| 加密和版本配置 | 核实维护状态、算法/参数及上下文；读取相关解释 | PY-COMMON-2.1.1、JAVA-BACKEND-1.8.1、PY-COMMON-1.3.3 |
| 内存、并发、资源释放 | 校验边界与失败分支，保证生命周期及并发访问符合实际语言语义 | CPP-COMMON-2.4、CPP-COMMON-7.1、GO-BACKEND-1.9.1 |

若原文绑定组织政策（例如日志保存期限、账号体系、个人信息展示方式），先查看项目实际要求，不能把某个组织的默认值当成所有项目的统一规定。隐藏接口地址属于附加措施，不能代替服务端鉴权。

示例中对 URL、路径或命令字符的有限黑名单不等于完整安全边界。仍需理解实际解析、调用、权限和平台语义；不要把“过滤几个字符”当成已经通过安全检查。
